## Security and compatibility rules

- **WoW 3.3.5a / Lua 5.1 only**. Use supported stock client templates/textures. Avoid  retail-only API calls and anonymous `UIPanelScrollFrameTemplate` (Wrath's OnLoad requires a named frame).
- The working Apply targeting uses a **hardware-click `SecureActionButtonTemplate` + `/targetexact <BotName>`**, set up out of combat. Do **not** change this to `TargetByName`, an insecure macro call, or an automatic chat/server Apply. Changing targets by itself cannot dispatch a request.
- Every actual Apply is separate from browsing, loading, saving and Preview. Maintain intended bot name/class/GUID checks, subsequent Apply click where a new target was just selected, and the final explicit confirmation.
- Client requests only the existing `.naxxbot talents preview/apply <bot-name> <NT1-code>` over SAY. A successful `SendChatMessage` is only dispatch, **not server-confirmed talent application**. The server `NaxxramasCore.BotTalentImport.AccessMode=0` disables the experimental handler by default.
- Server-backed `APPLY_READY`, structured acknowledgement/receipt, level projection, equipment automation and guaranteed rollback are **not implemented**. Follow `docs/NT1-SERVER-INTEGRATION-CONTRACT.md`. Server project [Mod-Naxxramas-Core](https://github.com/CosmicCuddle/Mod-Naxxramas-Core) is maintained separately; do not edit C++, SQL, DBC or Playerbots from this UI workstream.
- Keep the published [N Addon Collection](https://github.com/CosmicCuddle/N-Addon-Collection) v2.0.0 **untouched** until explicit owner approval for release. Never merge the draft PR or publish the ZIP automatically.
